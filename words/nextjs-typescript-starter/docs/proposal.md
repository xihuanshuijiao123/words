# 学英语单词 H5 项目 — 需求文档 (Proposal)

## 1. 项目概述

本项目是一个面向移动端的 **H5 学英语单词应用**，让用户以单词卡片的方式背单词。

- 使用移动端 H5 形态，适配手机浏览器与微信内嵌浏览器。
- 底部提供「首页」「我的」两个 Tab 栏。
- 未登录用户可浏览单词书，点击单词书时触发登录/注册弹窗。
- 已登录用户可看到最近学习进度，并从上次学习位置继续学习。

---

## 2. 需求范围与目标

| 目标        | 说明                                                       |
| ----------- | ---------------------------------------------------------- |
| 单词书浏览  | 首页展示所有单词书（封面、标题、单词数、标签）             |
| 最近学习    | 登录后展示最近正在学习的单词书，点击可续学                 |
| 学习卡片    | 单词学习中逐词展示卡片，下一页切换                         |
| 单词详情    | 点击卡片进入单词详情页，展示完整释义、例句、短语、同根词等 |
| 登录 / 注册 | 未登录点击单词书时弹出登录弹窗，支持邮箱密码登录与注册     |
| 个人中心    | 展示用户邮箱、学习进度、退出登录                           |

**非目标（本期不做）**：单词书管理后台（已有单独的后台系统）、付费、社交分享、在线词典发音录制等。

          {
            "tranCn": "尺子",
            "descCn": "中释",
            "descOther": "英释",
            "tranOther": "a long flat ..."
          }
        ],
        "phrase": {
          "phrases": [{ "pContent": "pencil case", "pCn": "文具盒" }]
        },
        "syno": {
          "synos": [

          ]
        },

          "rels": [

## 4. 总体信息架构与页面结构

```
App（移动端 H5）
├── Tab 容器（底部：首页 / 我的）
│   └── 首页 (Home)
│       ├── 最近学习（登录且有进度时展示）
│       └── 全部单词书（卡片列表）
│   └── 我的 (Profile)
│       ├── 未登录：登录 / 注册
│       └── 已登录：用户信息 / 进度 / 退出
└── 学习页 (Learn)          ← 从首页单词书或最近学习进入
    └── 单词学习卡片
        └── 单词详情页 (Word Detail)  ← 点击卡片进入
```

### 页面路由规划（Next.js）

| 路由                      | 页面             | 说明                   |
| ------------------------- | ---------------- | ---------------------- |
| `/`                       | 首页 Tab（默认） | 单词书列表 + 最近学习  |
| `/profile`                | 我的 Tab         | 用户信息 / 进度 / 退出 |
| `/learn/[bookId]`         | 学习页           | 单词卡片学习           |

### 5.2 首页（Home）

**状态一：用户已登录且有学习进度**

从上到下依次为：

1. **最近学习模块**（最近一次学习的单词书）
   - 展示：书名、封面、标签、上次学到第几个/共几个词、进度条、继续学习按钮。
   - 点击整块区域跳转到 `/learn/[bookId]`，并从上次学习到的下一个单词开始。
   - 若无进度数据，则不展示该模块（下方直接为全部单词书）。
2. **全部单词书**
   - 列表展示所有单词书（封面、标题、单词数量、标签）。
   - 点击单词书卡片进入 `/learn/[bookId]`，从该书的第 1 个单词开始（或继续上次进度）。

**状态二：用户未登录**

- 顶部只展示**全部单词书**，不展示最近学习模块。
- 点击任意单词书卡片 → 跳转到「我的」Tab，并自动弹出登录弹窗（见 §5.5）。

### 5.3 学习页（Learn）— 单词卡片

- 仅展示一条**实例**（一个词条），保持简洁。
- 卡片上展示字段（从 `content.word.content` 提取）：

| 字段     | 来源                    | 说明                                |
| -------- | ----------------------- | ----------------------------------- |
| 单词     | `headWord`              | 大字展示                            |
| 音标     | `usphone` / `ukphone`   | 显示 1 个（默认美音）               |
| 发音按钮 | `usspeech` / `ukspeech` | 点击播放读音                        |
| 中文释义 | `trans[].tranCn`        | 简明中释                            |

- 学习到某词时，把该词标记为「进度」并记录到进度状态（见 §5.6）。
- 点击卡片或「查看详情」按钮跳转到单词详情页 `/word/[bookId]/[wordId]`。

### 5.4 单词详情页（Word Detail）

进入方式：学习页点击卡片或「查看详情」。

渲染 `content.word.content` 的完整字段：

| 模块   | 字段                                                |
| ------ | --------------------------------------------------- |
| 单词头 | `wordHead`、`usphone`、`ukphone`、发音按钮（美/英） |

### 5.5 我的（Profile）— 登录 / 注册弹窗

**未登录状态**

- 页面展示登录/注册入口，点击进入登录弹窗（或底部 Tab「我的」时自动弹出）。
- 登录弹窗（`Dialog`）：邮箱 + 密码 + 登录按钮。
- 弹窗中提供「注册」切换：姓名 + 邮箱 + 密码 + 确认密码。
- 校验规则复用后台逻辑：
  - 邮箱格式：`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
  - 密码至少 6 位；注册两次密码必须一致。
- 登录成功后：关闭弹窗，回到「我的」展示用户信息；若从单词书点击进入，则继续跳转该单词书的学习页。

> 交互触发：未登录点单词书 → 切到「我的」Tab → 弹出登录弹窗。也可在「我的」Tab 直接点击「登录 / 注册」按钮弹出。

### 5.6 学习进度与「最近学习」数据设计

当前无学习进度表，需新增。推荐以下两种方案（二选一，需实现时确认）：

**方案 A（推荐）：服务端存储，与后台一致**

- 新增表 `study-records`：
  ```sql
  study-records(
    id          uuid PK,
    userId      uuid FK → adminUsers.id,
    bookId      text,             -- 关联 books.bookId
    wordId      text,             -- 最近学到的词 wordId
    lastRank    integer,          -- 最近学到的 wordRank
    progress    integer,          -- 已完成数量
    updated_at  timestamp
  )
  ```
- 唯一约束：`(userId, bookId)` 唯一。
- 「最近学习」= 按 `updated_at` 降序取第一条。
- 学习页每学完一词调用一次更新接口 `/api/study-progress`。

**方案 B（简单）：前端本地存储**

- 在 `localStorage` 中按 `userId` 保存 `bookId → { lastRank, progress, updatedAt }`。
- 无需后端改动，但跨设备/清缓存会丢失。

> 文档说明：建议方案 A，数据可跨端同步，且与后台的书/单词数据同源；方案 B 更轻量。

## 6. 数据接口设计（H5 侧）

| 接口                    | 方法    | 说明                                     |

| 场景           | 处理                                       |

## 8. 非功能性需求

- **适配**：移动端优先，安全区（iPhone 底部横条）padding 适配，底部 Tab 使用 `env(safe-area-inset-bottom)`。
- **性能**：单词列表按需加载/分页；卡片切换无整页刷新（前端状态切换）。
- **可访问性**：按钮有可点击区域与 focus 态；可读性字号。
- **视觉**：与后台风格统一（使用现有 shadcn/ui 组件如 `Card`、`Dialog`、`Input`、`Button`），主色一致。
- **技术栈**：Next.js（App Router）+ TypeScript + Tailwind + shadcn/ui。

## 9. 验收要点

1. 底部「首页 / 我的」两个 Tab 可切换且高亮正确。
2. 未登录首页只显示单词书；点击单词书跳「我的」并弹出登录/注册弹窗。
3. 登录/注册校验与后台一致；成功后进入对应单词书学习页。
4. 已登录首页显示「最近学习」+「全部单词书」；无进度时不显示「最近学习」。
5. 学习页以单词卡片展示单个词条（单词+音标+发音+中释+一条例句），「下一个」可切词。
6. 点击卡片进入单词详情页，完整渲染例句/短语/同根/记忆等。
7. 学习页记录进度；「我的」展示邮箱、进度、退出登录。
